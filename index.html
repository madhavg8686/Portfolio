Projects

Lambda safe deployment: blue/green and canary

Terraform · Lambda · API Gateway · CloudWatch

Releases use immutable Lambda versions and a weighted alias behind an API Gateway REST API (AWS_PROXY). Shifting traffic is a Terraform variable change, not a redeploy.

  • Traffic steering: blue/green flips 100% of traffic; canary sends a configurable share (default 10%).
  • Rollback: CloudWatch alarms watch errors and duration; rolling back means repointing the alias.

Monitor 53: website monitoring and alerting on AWS

Route 53 · CloudWatch · SNS · Terraform

A low-cost endpoint monitor defined in Terraform. Route 53 health checks probe from several AWS regions with configurable failure thresholds, and alarms notify by email through SNS under least-privilege IAM.

  • Health probes: HTTP/HTTPS checks with custom interval and failure tolerance.
  • Alerting: CloudWatch alarms publish to an SNS topic that emails the on-call address.

Doc_RAG: AWS Solutions Architect study assistant

Python · FAISS · Ollama Llama 3.2 · OpenAI embeddings

A retrieval-augmented assistant that answers architecture questions from a Solutions Architect study guide PDF. It extracts text with PyPDF2, embeds chunks with OpenAI embeddings, and searches a persistent FAISS index.

  • Embed once: the index and chunk metadata are saved to disk, so the PDF is only embedded on the first run.
  • Local answers: retrieved chunks go to a local Ollama Llama 3.2 model, so answers stay grounded in the document.
